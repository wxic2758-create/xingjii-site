几秒完成图片重命名

ImageRenamer 是一款适用于 macOS 的私密、离线批量重命名工具。添加图片或文件夹，预览结果，然后导出重命名后的副本。

使用技巧

  • 使用“添加图片”或“添加文件夹”导入文件。
  • 设置前缀、后缀、起始编号和位数。
  • 导出前查看实时文件名预览。
  • macOS 请求权限时，选择输出文件夹。

获取支持

欢迎来信咨询、反馈 Bug 或提出建议。请附上 macOS 版本和问题的简要说明。除非复现问题确有必要，请不要附上私人图片。

需要更小的图片文件？

CompressBox 可在 Mac 本地压缩图片和视频。

反馈 Bug？

请附上 macOS 版本、App 版本和问题的简要说明。除非复现问题确有必要，请不要附上密码、私钥或私人图片。
