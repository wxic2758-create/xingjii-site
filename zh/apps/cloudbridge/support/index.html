关于 CloudBridge

CloudBridge 帮你连接自己的 SSH/SFTP 服务器，浏览远程文件夹，用快速查看预览文件，并把文件或文件夹下载到 Mac。

常见问题

需要注册 CloudBridge 账号吗？

不需要。CloudBridge 连接的是你自己提供并管理的服务器。

密码保存在哪里？

保存的服务器密码安全地存放在 macOS 钥匙串中，CloudBridge 连接该服务器时在本机读取。密码只会通过 SSH 发送给该服务器。

为什么文件夹大小显示为“-”？

SFTP 服务器上的远程目录大小容易产生误导，所以 CloudBridge 对文件夹显示“-”，而不是一个固定的占位大小。

运行需要什么？

macOS 14 或更高版本。

如何删除已保存的凭据？

断开连接，编辑该服务器，选择“移除已保存的密码”。删除服务器会同时删除其本地保存的配置和钥匙串凭据。

联系支持前请先确认

  • 服务器主机、端口、用户名和认证方式填写正确。
  • 服务器支持 SFTP 访问。
  • 你的网络、防火墙或云服务商安全组允许 SSH/SFTP 连接。

反馈 Bug？

请附上 macOS 版本、App 版本和问题的简要说明。除非复现问题确有必要，请不要附上密码、私钥或私人图片。
