专注的 Mac 小工具，文件始终留在你的 Mac 上。

独立开发的原生实用工具，每个只做好一件事。图片在本地处理、从不上传；服务器文件直接从你的服务器下载到 Mac。

CloudBridge: SFTP Transfer

Mac SFTP 客户端，浏览并下载你自己服务器上的文件。

  • SSH / SFTP 密码登录
  • 快速查看（Quick Look）预览远程文件
  • 下载可暂停、继续、重试

CompressBox: 图片压缩

Mac 图片压缩，本地批量压缩图片和视频。

  • PNG、JPEG、WebP、BMP、ICO、GIF
  • MP4、MOV、M4V 视频
  • PNG 无损优化

ImageRenamer: Batch Rename

Mac 批量重命名图片：前缀 + 序号 + 后缀。

  • 前缀 + 补零序号 + 后缀
  • 拖动排序、按内容查重
  • 导出副本，不改原文件

按任务选工具

从你要完成的事情出发。

🗜️

压缩图片

分享或上传前，把一整个文件夹的照片、截图变小。

打开 CompressBox →指南：在 Mac 上批量压缩图片
🏷️

批量重命名图片

给几百个文件起整齐有序的名字，原文件不动。

打开 ImageRenamer →指南：批量重命名图片且不改原文件
🖥️

从服务器取文件

预览并下载 VPS、NAS 或 SFTP 服务器上的文件。

打开 CloudBridge →指南：在 Mac 上从 SFTP 服务器下载文件
