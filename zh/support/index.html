反馈 Bug？

请附上 macOS 版本、App 版本和问题的简要说明。除非复现问题确有必要，请不要附上密码、私钥或私人图片。

CloudBridge: SFTP Transfer

需要注册 CloudBridge 账号吗？

不需要。CloudBridge 连接的是你自己提供并管理的服务器。

密码保存在哪里？

保存的服务器密码安全地存放在 macOS 钥匙串中，CloudBridge 连接该服务器时在本机读取。密码只会通过 SSH 发送给该服务器。

CloudBridge 技术支持 →隐私政策App Store

CompressBox: 图片压缩

压缩后的文件保存在哪里？

压缩后的文件保存在本地“下载”文件夹。

为什么文件没怎么变小？

已高度优化的文件在不降低质量的前提下可能无法显著变小。若输出体积变大，请尝试降低质量设置或保留原始格式。

CompressBox 技术支持 →隐私政策App Store

ImageRenamer: Batch Rename

会修改原文件吗？

不会。ImageRenamer 把重命名后的副本导出到新文件夹，源文件及其原名保持不变。

如何导入图片？

使用“添加图片”或“添加文件夹”，也可以从访达添加。

ImageRenamer 技术支持 →隐私政策App Store
