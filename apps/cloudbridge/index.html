Frequently asked questions

Do I need a CloudBridge account?

No. CloudBridge connects to servers that you provide and control.

Where are passwords stored?

Saved server passwords are stored securely in macOS Keychain and are retrieved locally when CloudBridge connects to that server. The password is sent only to that server through SSH.

Why do folders show size as “-”?

Remote directory sizes can be misleading on SFTP servers, so CloudBridge shows “-” for folders instead of a fixed placeholder size.

What do I need to run it?

macOS 14 or later.
